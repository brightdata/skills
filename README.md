# Bright Data Skills

Skills that teach a coding agent how to get web data with Bright Data.

This catalog is being reorganized. Seventeen retired skills were removed in this change, and the remaining set is being refreshed in follow-up pull requests. The current folders live under `skills/`, and each one is a folder with a SKILL.md plus reference files.

Install with the Bright Data CLI (`npm install -g @brightdata/cli`, then `bdata skill add <name>`), or clone the repo and copy the folders you want into your agent's skills directory.
